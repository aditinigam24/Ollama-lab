# OLLAMA LAB — Your First Journey Into Local AI

Interactive Ollama workshop site (React + Vite + TypeScript + Tailwind + Framer Motion + React Three Fiber).

## Run it
    npm install
    npm run dev        # development at http://localhost:5173
    npm run build      # production build in dist/
    npm run preview    # serve the production build

## Presenting
Click "Presentation mode" (top right). Use ← / → to move between the 12 sections, Esc to exit, "Fullscreen" for projector mode.

## Notes
- The terminal playground is a simulation; nothing is executed on the student's computer.
- No API key or backend needed. Fonts load from Google Fonts (works offline with system-font fallback).
- Always cross-check commands with https://docs.ollama.com/ before the workshop; versions and model sizes change.
